countries.json: country outlines for the offline country lookup (geo/Countries.kt).

Source: Natural Earth 1:110m Cultural Vectors, Admin 0 - Countries (ne_110m_admin_0_countries.geojson,
https://github.com/nvkelso/natural-earth-vector). Natural Earth is in the public domain
(https://www.naturalearthdata.com/about/terms-of-use/).

Reduced for the app: per country only a code and the polygons, coordinates rounded to 3 decimals.
Code = ISO_A2, or ISO_A2_EH when ISO_A2 is "-99" (France, Norway, Kosovo; Taiwan's "CN-TW"), else ADM0_A3
(N. Cyprus "CYN", Somaliland "SOL").
Format: {"v":1,"c":[{"a":"GR","p":[[[lng,lat,lng,lat,...],[hole...]], ...more polygons]}, ...]}

1:110m is coarse: small islands are missing and coasts are off by a few km, so the app also accepts the nearest
outline within a short distance and falls back to Android's Geocoder.
